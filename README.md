# Mi Amigo Secreto 🎁

App web para organizar el intercambio de regalos de Navidad: crea un grupo, comparte el código, cada quien se une desde su teléfono y el sorteo asigna en secreto a quién le regala cada uno.

*Secret Santa web app: create a group, share the code, everyone joins from their phone and the draw is assigned in secret.*

Next.js · TypeScript · Tailwind · PWA
